# 核心理念

这些理念用于约束 iMacSwitch 的实现与维护方向。

## Agent-First 的工作原则

- 人来定方向，Agent 负责执行和推进。
- 仓库内可追溯的知识，比私有上下文更重要。
- Agent 反复失败时，优先修脚手架和环境，不是继续加 prompt 压力。
- 短而稳定的入口文档，比越来越长的大 prompt 更可靠。
- 能变成机械检查的约束，就不要只停留在口头规范。
- 速度很重要，但无节制地堆积熵会迅速拖垮效率，所以要持续整理和收口。

## 产品原则

- 保持单一职责：可靠地移动用户明确选中的输入设备。
- 没有经过安全预检，不释放本机外设。
- 不依赖同一局域网，也不引入云端中继。
- 自动切换是主路径，手动控制只承担设置与故障恢复。
